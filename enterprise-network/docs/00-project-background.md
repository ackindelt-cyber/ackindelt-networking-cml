## Background

Talos Solutions is a fictional company created for this network design and simulation project.

The name comes from Talos, my dog and best friend. Talos was with me during some of the most difficult and important parts of my life. He was there when I came home from shifts working as an FMV analyst in the Army, and he was there after I left the Army, when I needed companionship, stability, and something steady to come home to.

Using his name for this project is a small way to honor him while building something meaningful for my professional development.

This lab is not just a collection of isolated networking exercises. It is intended to become a complete simulated enterprise environment with realistic design decisions, documentation, configurations, verification, failure testing, and future expansion paths.

Using the Talos Solutions name gives the project a consistent identity while keeping the technical design organized around a fictional business scenario.

## Name Clarification

Talos Solutions is a fictional organization created only for this lab project.

The name is not affiliated with Cisco Talos, Talos Threat Intelligence, or any Cisco-owned security research or threat intelligence organization. Any similarity in naming is coincidental. In this project, Talos refers to the personal origin described above and is used only as the fictional company name for the simulated enterprise network.

---

## Project Context

Talos Solutions represents a small-to-medium enterprise campus network.

The current v1 design focuses on building a stable enterprise network foundation using Cisco Modeling Labs. The design includes an ISP simulation, customer edge router, routed firewall boundary, dual collapsed core/distribution switches, Layer 2 access switches, centralized infrastructure services, gateway redundancy, access uplink redundancy, and operational verification.

Future versions may expand Talos Solutions into a more complete enterprise environment with additional services, security hardening, monitoring, automation, and multi-site network design.
